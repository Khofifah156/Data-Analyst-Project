# Analisis Tren Gaji, Level Pengalaman, dan Pola Kerja Profesi Data Science di Pasar Global

Project ini membahas analisis pasar kerja Data Science secara global dengan melihat tren gaji, level pengalaman, dan pola kerja berdasarkan dataset *Data Science Job Salaries* dari Kaggle.

Data melalui tahap cleaning, pengecekan missing value dan duplikat, transformasi kategori, serta pembentukan variabel `work_mode` berdasarkan tingkat remote. Selanjutnya dilakukan exploratory data analysis untuk mengidentifikasi pola gaji berdasarkan tahun, pengalaman, dan pola kerja. Hasil analisis disajikan dalam bentuk visualisasi dan dashboard untuk memberikan gambaran mengenai perkembangan profesi Data Science di pasar global.
